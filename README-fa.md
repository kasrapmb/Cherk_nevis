# قالب قابل ویرایش Blue Motion

بازسازی بصری قالبِ ویدئوی ارسالی، در نسبت تصویر ۱۶:۹؛ شامل فایل پاورپوینت، قالب POTX، پیش‌نمایش و سورس تولید فایل‌ها.

## شروع سریع

۱. برای شروع، `output/blue-motion-fa.pptx` را در **نسخهٔ دسکتاپ Microsoft PowerPoint دارای Morph** باز کنید. برای نمونهٔ انگلیسی مشابه ویدئو، `output/blue-motion.pptx` را باز کنید.

۲. برای دیدن حرکت‌ها، از ابتدای فایل Slide Show را اجرا کنید (در ویندوز: F5). گزینهٔ **Slide Show → Use Timings** روشن باشد. اسلایدهای معرفی خودکار جلو می‌روند؛ در اسلاید ۱۲، فهرست منتظر انتخاب شما می‌ماند. روی عنوان یا علامت + بزنید تا بخش باز شود؛ دوباره همان ردیف را بزنید تا بسته شود. «ورود به بخش» شما را به اسلاید محتوای مربوط می‌برد.

۳. متن‌ها را مستقیم ویرایش کنید. برای تولید یک ارائهٔ تازه از قالب، فایل `.potx` را با دوبار کلیک باز کنید و نتیجه را با نام تازه به صورت `.pptx` ذخیره کنید.

## ساختار اسلایدها

| اسلاید | کاربرد |
|---|---|
| ۱ تا ۴ | لوگو روی سفید، گسترش لوزی، موزاییک آبی و معرفی برند |
| ۵ و ۶ | ورود تصویر و تشکیل جلد |
| ۷ تا ۱۱ | حرکت به فهرست و آشکارشدن چهار ردیف |
| ۱۲ | فهرست تعاملی در حالت بسته |
| ۱۳ تا ۱۶ | چهار حالتِ بازشدهٔ فهرست |
| ۱۷ تا ۲۰ | چهار اسلاید برای متن خودتان؛ افزودهٔ کاربردیِ این بازسازی |

۲۰ اسلاید به معنی ۲۰ طرح متفاوت نیست: بخشی از اسلایدها حالت‌های متوالی یک حرکت‌اند. حذف اسلایدهای میانی، حرکت را تغییر می‌دهد.

## شخصی‌سازی در PowerPoint

- **متن:** متن داخل کادرها را تغییر دهید. عنوان‌ها و مشخصات برند در چند حالت تکرار شده‌اند؛ در تمام حالت‌های مربوط آن‌ها را یکسان تغییر دهید. برای تغییر یک عبارت تکراری از Replace استفاده کنید.
- **تصویر:** تصویر آبی را انتخاب کنید و از Change Picture تصویر خودتان را جایگزین کنید. این کار را برای تمام حالت‌های دارای تصویر انجام دهید. تصویر، یک دارایی رستری مستقل است؛ متن‌ها و اشکال، تصویر تخت‌شده نیستند.
- **لوگو:** علامت فعلی از چند شکل ساده تشکیل شده است. آن‌ها در Selection Pane با نام‌های `!!logo-…` مشخص شده‌اند. تغییر یکپارچهٔ لوگو از طریق تنظیمات و بازتولید فایل که پایین توضیح داده شده، راحت‌تر است.
- **رنگ:** رنگ زمینه و شکل‌های انتخاب‌شده را از Format تغییر دهید. برای تغییر همهٔ حالت‌ها به صورت یکپارچه، از فایل تنظیمات استفاده کنید. تغییر پالت Theme به تنهایی رنگ تمام شکل‌ها را عوض نمی‌کند، چون برای بازسازی قابل پیش‌بینی از رنگ‌های مستقیم استفاده شده است.
- **سرعت:** در Transitions مقدار Duration را تغییر دهید. برای معرفی، After زمان مکث پس از گذار را تعیین می‌کند. روی اسلایدهای ۱۲ تا ۲۰ گزینهٔ After خاموش است.
- **اسلاید جدید:** یکی از اسلایدهای ۱۷ تا ۲۰ را Duplicate کنید و محتوای خودتان را وارد کنید. برای حفظ زنجیرهٔ معرفی، حالت‌های ۱ تا ۱۶ را جابه‌جا نکنید.
- **Morph:** نام‌های شروع‌شده با `!!` را در Selection Pane نگه دارید؛ این نام‌ها هویت عناصر مشترک را برای Morph مشخص می‌کنند. برای جابه‌جایی یک عنصر، خود همان عنصر را تغییر دهید و آن را حذف و دوباره ایجاد نکنید.
- **متن بلند:** توضیحات فهرست برای ۲ تا ۴ خط کوتاه طراحی شده‌اند. متن طولانی‌تر را در اسلاید محتوای مربوط قرار دهید. اندازه‌ها و زمان‌بندی اصلی برای همین متن‌های نمونه بررسی شده‌اند.

## تغییر یکپارچه با تنظیمات

برای اینکه نام، متن، رنگ و لوگو در تمام حالت‌ها همزمان عوض شوند، `content-fa.json` یا `content.json` را ویرایش کنید. چهار بخش فهرست را نگه دارید.

کلیدهای اصلی:

| کلید | کاربرد |
|---|---|
| `brand` و `brand_tagline` | نام و شعار برند |
| `presenter` و `role` | نام و مشخصات ارائه‌دهنده |
| `title` و `subtitle` | عنوان و زیرعنوان؛ `\n` برای شکستن خط |
| `sections` | عنوان، توضیح کوتاه، تیتر و متن چهار بخش |
| `colors` | کد رنگ شش‌رقمی بدون # |
| `font` | فونت نصب‌شده روی رایانهٔ مقصد |
| `rtl` | راست‌به‌چپ بودن متن‌ها |
| `hero_path` | اختیاری؛ مسیر عکس نسبت به پوشهٔ پروژه، مثلاً `assets/my-photo.jpg` |
| `secondary_hero_path` | اختیاری؛ تصویر حالتِ بازشدهٔ بخش دوم؛ پیش‌فرض `assets/blue-bloom.jpg` |
| `logo_path` | اختیاری؛ مسیر لوگوی مربعی PNG، مثلاً `assets/my-logo.png`؛ با حذف این کلید، علامت هندسی فعلی استفاده می‌شود |

با Python 3 و وابستگی‌های ثبت‌شده در `requirements.txt`:

```bash
cd Cherk_nevis
python -m pip install -r requirements.txt
python tools/build_template.py --content content-fa.json --name my-presentation
```

نتیجه در پوشهٔ `output` ذخیره می‌شود. دستور بازتولید، فایل‌های خروجی هم‌نام را جایگزین می‌کند؛ ویرایش‌های دستی خود را ابتدا با نام دیگری ذخیره کنید. برای ورود لوگوی خودتان نیازی به ماکرو یا نصب افزونه در PowerPoint نیست.

## پیش‌نمایش و حدود بازسازی

- `output/motion-preview.mp4` پیش‌نمایش حرکت‌هاست؛ این فایل **شبیه‌سازی مرورگر** است و ضبط اجرای PowerPoint نیست.
- `output/blue-motion-fa-preview.html` مستقل است و بدون اتصال اینترنت در مرورگر باز می‌شود. Play intro معرفی را اجرا می‌کند؛ سپس روی فهرست کلیک کنید. نسخهٔ انگلیسی هم موجود است.
- فایل‌ها گذار بومی Morph و fallback از نوع Fade دارند. برای حفظ حرکت‌ها از PowerPoint دارای Morph، ترجیحاً Microsoft 365 دسکتاپ، استفاده کنید. Google Slides، LibreOffice و نسخه‌های قدیمی ممکن است حرکت‌ها را به شکل متفاوت یا فقط با Fade نشان دهند.
- ساختار ZIP/XML، ارجاعات داخلی، قابل ویرایش بودن متن‌ها و شکل‌ها و جفت گذارهای Morph/Fade بررسی شده‌اند. همهٔ صحنه‌های پیش‌نمایش انگلیسی و فارسی از نظر سرریز متن و لینک‌های فهرست بررسی شده‌اند. **اجرای واقعی Morph در Microsoft PowerPoint در این محیط انجام نشده است.**
- از روی MP4 نمی‌شود فایل اصلی، فونت دقیق، تصویر اصلی، تنظیمات گذار یا نحوهٔ ساخت آن را بازیابی قطعی کرد. این فایل بازسازی رفتار و چیدمان دیده‌شده است، نه نسخهٔ استخراج‌شدهٔ فایل اصلی. تصویر آبی برای این پروژه تولید شده و علامت نمونه قابل جایگزینی است؛ واترمارک و حساب سازندهٔ ویدئو در قالب کپی نشده‌اند.
- طبق اسکیل [REA](https://github.com/kasrapmb/REA_skills_Codex)، مشاهده، استنباط و مجهول جدا شده‌اند. این اسکیل مسیر مستقیمی برای مهندسی معکوس MP4 ندارد؛ تحلیل فریم‌ها با FFmpeg انجام شده و خروجی به عنوان Evidence موتور REA معرفی نشده است. گزارش در `reference/analysis.md` قرار دارد.

## آزمون‌های قابل تکرار

```bash
python tools/validate_pptx.py
python tools/check_preview.py
python tools/capture_motion.py
```

دو دستور آخر به Playwright و Chromium نیاز دارند؛ برای استفاده یا ویرایش فایل‌های پاورپوینت به آن‌ها نیاز نیست. مسیر Chromium در اسکریپت‌ها `/usr/bin/chromium` است و می‌توانید آن را مطابق سیستم خود عوض کنید.
